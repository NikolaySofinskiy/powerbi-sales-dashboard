# Power BI sales dashboard

Интерактивный дашборд по продажам в Power BI: путь от сырых данных до дашборда.

Проект демонстрирует полный цикл аналитики в Power BI: загрузка и очистка данных из разных источников (Excel, XML, PDF, TXT), построение модели данных по схеме «звезда», расчет мер на DAX и визуализация ключевых бизнес-метрик.

---

## 🎯 Цель проекта

Построить интерактивный дашборд по продажам, который позволяет:

- Анализировать **выручку** (руб) с разбивкой по **компаниям** и **товарам**.
- Анализировать **продажи в штуках** с разбивкой по **регионам**.
- Делать **срез по годам** (2023–2025).
- Смотреть динамику продаж по месяцам.
- Выявлять топовые товары, компании и регионы.

Проект демонстрирует навыки построения аналитического отчёта в Power BI:
загрузка и очистка данных (Power Query), построение модели данных, написание мер на DAX, визуализация через встроенные визуалы Power BI.

## 🔄 Этапы реализации

### 1. Загрузка данных

- Подключение к исходным файлам (`sales.xlsx`, `customers.xml`, `price.pdf`, `regions.txt`) через Power Query.
- Первичный осмотр структуры, типов данных, аномалий.

### 2. Обработка данных (Power Query)

`price.pdf`:
- подключение к PDF
- проверка корректности распознавания таблицы
- отделим наименование товара от страны производителя: разделить столбец "Наименование" по разделителю #(lf),
  удаляем столбец со страной, в наименовании товара убираем пробелы (усечь), переименовываем столбец на "Товар"
- меняем тип данных в столбце "Объем" на текст
- переименование запроса в `Price`
- загружаем таблицу - закрыть и применить

`customers.xml`:
- подключение к XML
- редактируем столбец "Местоположение": заменяем "г." на "", убираем пробелы - "Усечь",  отделяем город от улицы - разделить
  столбец по разделителю ",", самый левый разделитель
- переименовываем колонки: "Местоположение.1" на "Город" и "Местоположение.2" на "Адрес"
- меняем имя запроса на "Сustomers"
- загружаем таблицу - закрыть и применить

`regions.txt`:
- загрузка как CSV с разделителем `;`
- поднимаем первую строку в заголовки - использовать первую строку в качестве заголовков
- меняем имя запроса на "Regions"
- загружаем таблицу - закрыть и применить
  
`sales.xlsx`:
- загружаем excel файл
- удаление строк «Итог» и пустых строк-разделителей
- заполнение вниз даты продажи (объединённые ячейки по дню)
- меняем тип данных в столбце с датой на дата
- переименование запроса в `Sales`
- загружаем таблицу - закрыть и применить

### 3. Модель данных
Устанавливаем связи в модели данных

<img width="1122" height="756" alt="image" src="https://github.com/user-attachments/assets/c3cf2ba3-7b52-4d33-873b-1e789d262e36" />

Схема — **«звезда» (star schema)**:

- **Таблица фактов:** `Sales`
- **Таблицы измерений:** `Price`, `Customers`, `Regions`



### 4. Меры DAX

```dax
Выручка = SUMX(SalesPrepared, SalesPrepared[Количество] * RELATED(ProductsPrepared[Цена]))

Продажи, шт = SUM(SalesPrepared[Количество])

Средний чек = DIVIDE([Выручка], DISTINCTCOUNT(SalesPrepared[Номер заказа]))

Кол-во компаний = DISTINCTCOUNT(SalesPrepared[Код клиента])

Выручка прошлого года = CALCULATE([Выручка], SAMEPERIODLASTYEAR(Календарь[Дата]))

Динамика год к году, % = DIVIDE([Выручка] - [Выручка прошлого года], [Выручка прошлого года])
```

### 5. Визуализация (дашборд)

- **Карточки KPI:** общая выручка, продажи в шт, средний чек, кол-во компаний.
- **Матрица:** выручка по компаниям и товарам.
- **Гистограмма:** продажи в шт по регионам.
- **Линейный график:** динамика выручки по месяцам.
- **Срез по годам** (2023 / 2024 / 2025).
- **Срез по регионам / федеральным округам**.
- **Топ-N товаров** по выручке.
